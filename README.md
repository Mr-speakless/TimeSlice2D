# Time Slice 2D

An experiment in cutting video through time. The frames of a video are stacked into a 3D cube (x and y are the image, depth is time), and a 2D plane slices through it at any angle. Every pixel on the slice comes from a different moment, so rotating and moving the plane opens up new possibilities for moving-image narrative.

This is a small experiment made before my final project for *Canvas for Code*.

Built with Three.js, React and shadcn/ui.

```bash
npm install
npm run dev
```
